# Evidence Logbook

A phone-friendly app for apprentices to plan, capture and organise workplace evidence for their unit books.

- Reads a unit book (PDF or page photos) and turns it into an evidence checklist per unit
- Take a photo, add your own note, and the AI suggests which checklist item it belongs to
- Photos save into the apprentice's own OneDrive, one folder per unit
- Credit counter, draft packs, and a printable evidence pack with a trainer sign-off page

The app never writes notes, answers or evidence for the apprentice. Only the trainer or assessor signs units off.

Setup: see [SETUP.md](SETUP.md). Try it without setup: add `?demo=1` to the app address.
